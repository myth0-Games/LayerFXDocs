# Version Support

Please refer to the following table to check version compatibility.

| Unity Version | Universal Render Pipeline (URP) | High Definition Render Pipeline (HDRP) | Built-in Render Pipeline |
| --- | --- | --- | --- |
| Unity 6000.5.3f1 | ✅ Supported | ❌ Unsupported | ❌ Unsupported |
| Unity 6000.3.11f1 (LTS) | ✅ Supported | ❌ Unsupported | ❌ Unsupported |
| Unity 6000.0.79f1 (LTS) | ✅ Supported | ❌ Unsupported | ❌ Unsupported |
| Previous releases (Lower than Unity 6000.0) | ❌ Unsupported | ❌ Unsupported | ❌ Unsupported |
| Beta versions | ⚠️ May introduce breaking changes | ❌ Unsupported | ❌ Unsupported |

**Note**: LayerFX is currently designed for the Universal Render Pipeline (URP). 
Support for HDRP and the Built-in Render Pipeline is not planned at this time.
